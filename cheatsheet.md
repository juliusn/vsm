# VSM maintenance cheat sheet

## Common commands

Generate local Supabase types:

```bash
npm run supabase:types
```

Dump local database data:

```bash
npm run db:dump
```

Reset local database:

```bash
npm run db:reset
```

Output database diff:

```bash
npm run db:diff
```

Create a new migration:

```bash
npm run db:migration -- migration_name
```
